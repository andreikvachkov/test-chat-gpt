# Покупатели, сотрудники и права доступа

Покупатели входят через `/login`, сотрудники — через `/admin/login`. Это отдельные аккаунты: у каждого свой пароль, а одинаковая почта может использоваться в обоих списках. Регистрация покупателя не даёт доступа в админку. Вход сотрудника не заменяет вход покупателя при оформлении заказа.

## Создание сотрудников

Владелец открывает **Администрирование → Сотрудники → Создать**, указывает имя, почту, пароль и роль. Пароль должен содержать не менее 12 символов, буквы и цифры.

На странице сотрудника можно изменить роль, установить новый пароль или выключить «Доступ в админку включён». Пустое поле пароля при редактировании сохраняет прежний пароль. Блокировка закрывает доступ в том числе для уже вошедшего сотрудника. Последнего активного владельца нельзя заблокировать или перевести на другую роль.

Сотрудники не отображаются среди покупателей. Управлять сотрудниками и ролями могут только владельцы; это право нельзя выдать обычной роли.

## Роли

Начальные роли:

| Роль | Доступ |
| --- | --- |
| Владелец | Все разделы, включая сотрудников и роли |
| Управляющий магазином | Каталог, продажи и контент |
| Менеджер каталога | Товары, категории, атрибуты, подборки, отзывы и медиафайлы |
| Менеджер заказов | Заказы и клиенты |
| Редактор контента | Статьи, страницы и медиафайлы |

В **Администрирование → Роли и права** можно создать свою роль или изменить права существующей. Для каждого раздела предусмотрены чекбоксы просмотра, создания, изменения и удаления, если эти действия доступны в магазине. У товаров отдельно настраивается восстановление из корзины. Заказы и клиенты поддерживают просмотр и изменение, отзывы — просмотр, изменение статуса и удаление.

При обновлении существующие права на страницы распространяются на новый раздел статей. Права на отзывы наследуют только просмотр, изменение и удаление товаров — без дополнительных разрешений. Отдельный раздел текстов и ссылок удалён; его данные остаются в базе для работы витрины.

Для любого действия нужно включить «Просмотр». Роль только с этим правом позволяет открывать записи без редактирования. Ограничения проверяются при открытии адреса и выполнении действий, включая сохранение ранее открытой формы. Изменения прав действуют при следующем запросе сотрудника.

Системная роль «Владелец» не редактируется и не удаляется. Роль, назначенную сотрудникам, удалить нельзя: сначала выберите для них другую роль.

## Обновление существующей установки

После замены файлов проекта выполните:

```bash
bash scripts/docker.sh setup
```

Миграция переносит прежних администраторов в отдельный список сотрудников с ролью «Владелец» и сохраняет их пароли. После обновления войдите заново через `/admin/login`.

Если у прежнего администратора были заказы, избранное или данные профиля покупателя, его отдельный покупательский аккаунт сохраняется вместе с ними. Он больше не даёт административных прав. Обычные покупатели сотрудниками не становятся.

Для первой установки владелец создаётся из консоли:

```bash
bash scripts/docker.sh admin admin@example.com
```

Без Docker: `php artisan shop:admin admin@example.com`. Команда создаёт отдельного владельца, даже если покупатель с такой почтой уже существует. Последующих сотрудников можно создавать в самой админке.

Восстановление пароля покупателя относится только к покупательскому аккаунту. Пароль сотрудника владелец меняет в разделе «Сотрудники».
